# ⚡ PokeDex React Pro

Un centro de datos Pokémon moderno y de alto rendimiento que permite a los entrenadores analizar estadísticas, comparar especies y planificar sus equipos de combate con precisión.

## 🚀 Características Principales

*   **🔍 Exploración Completa:** Acceso a datos detallados de la PokeAPI con búsqueda instantánea y filtrado por tipos.
*   **⚖️ Comparador de Pokémon:** Enfrenta las estadísticas base de dos Pokémon cara a cara con gráficos visuales para identificar ventajas competitivas.
*   **🛠️ Team Builder:** Diseña y gestiona tu equipo ideal de 6 integrantes, visualizando las fortalezas y debilidades combinadas del equipo.
*   **📱 Diseño Full Responsive:** Interfaz moderna y minimalista construida con **Tailwind CSS**, optimizada para móviles y escritorio.
*   **⚡ Navegación Fluida:** Implementación de **HashRouter** para un despliegue perfecto en GitHub Pages y **React Query** para una gestión de caché eficiente.

## 🛠️ Stack Tecnológico

- **Frontend:** React (Vite)
- **Estilos:** Tailwind CSS + Lucide Icons
- **Estado Global & Fetching:** TanStack Query (React Query)
- **Enrutamiento:** React Router DOM (HashRouter)
- **UI Components:** Shadcn/ui (Radix UI)
